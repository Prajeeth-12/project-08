# AI Interview Agent — Integrated System

An AI-powered mock interview platform that reads your resume, conducts a live adaptive interview, and gives you a detailed scorecard with coaching.

## Architecture

Built by combining the best of two reference projects:
- **ai-interview-agent** — working multi-agent system (Gemini, Deepgram, Supabase)
- **module-2-ai-interview-agent** — deeper interview intelligence (ORDA agent loop, evidence tracking, rubric scoring)

## How to Run

```bash
# Backend
cd backend
pip install -r requirements.txt
python run.py

# Frontend
cd frontend
npm install
npm run dev
```
